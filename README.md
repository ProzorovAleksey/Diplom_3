# Diplom_3

Проект автоматизированного тестирования для веб-приложения Stellar Burgers с использованием Python, Selenium и Pytest.

Структура проекта
text
├── pages/                          # Page Object классы
│   ├── base_page.py                # Базовый класс для всех страниц
│   ├── main_page.py                # Главная страница
│   ├── forgot_password_page.py     # Восстановление пароля
│   ├── personal_acc_page.py        # Личный кабинет
│   └── order_feed_page.py          # Лента заказов
├── locators/                       # Локаторы элементов
│   ├── main_page_locators.py
│   ├── forgot_password_locators.py
│   ├── personal_acc_locators.py
│   └── order_feed_locators.py
├── tests/                          # Тестовые сценарии
│   ├── test_password_recovery.py   # Тесты восстановления пароля
│   ├── test_personal_acc.py        # Тесты личного кабинета
│   ├── test_main_functionality.py  # Основная функциональность
│   └── test_order_feed.py          # Тесты ленты заказов
├── conftest.py                     # Фикстуры Pytest
├── requirements.txt                # Зависимости проекта
├── urls.py                         # эндпоинты
└── README.md                       # Документация

Тестовое покрытие
1. Восстановление пароля
✅ переход на страницу восстановления пароля по кнопке «Восстановить пароль»

✅ ввод почты и клик по кнопке «Восстановить»

✅ клик по кнопке показать/скрыть пароль делает поле активным — подсвечивает его

2. Личный кабинет
✅ переход по клику на «Личный кабинет»

✅ переход в раздел «История заказов»

✅ выход из аккаунта

3. Основная функциональность
✅ переход по клику на «Конструктор»

✅ если кликнуть на ингредиент, появится всплывающее окно с деталями

✅ всплывающее окно закрывается кликом по крестику

✅ при добавлении ингредиента в заказ, увеличивается каунтер данного ингредиента

✅ залогиненный пользователь может оформить заказ

4. Лента заказов
✅ если кликнуть на заказ, откроется всплывающее окно с деталями

✅ заказы пользователя из раздела «История заказов» отображаются на странице «Лента заказов»

✅ при создании нового заказа счётчик Выполнено за всё время увеличивается

✅ при создании нового заказа счётчик Выполнено за сегодня увеличивается

✅ после оформления заказа его номер появляется в разделе В работе

Локаторы вынесены в отдельные файлы

Бизнес-логика отделена от реализации локаторов
